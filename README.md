**Windows Simple Dashboard**는 .NET 8.0 및 WPF 기반의 경량 시스템 모니터링 도구입니다. 복잡한 설정 없이 PC의 주요 리소스 상태를 직관적으로 파악할 수 있도록 설계되었습니다.

### ✨ 주요 특징 (Key Features)

* **실시간 리소스 추적**: CPU 사용량, RAM 점유율, 시스템 업타임을 실시간으로 모니터링합니다.
* **디스크 상태 가시화**: 각 드라이브의 사용량 및 여유 공간을 프로그레스 바로 제공합니다.
* **리소스 알림**: RAM 점유율이 90%를 초과할 경우 텍스트 색상이 변경되어 사용자에게 주의를 줍니다.
* **저사양 최적화**: 시스템 자원 소모를 최소화하여 백그라운드 구동 시에도 성능 저하가 거의 없습니다.
