### ✨ 주요 특징 (Key Features)

* **실시간 리소스 모니터링**: CPU 사용량, RAM 점유율, 시스템 업타임을 실시간으로 추적합니다.
* **디스크 상태 가시화**: 각 드라이브의 사용량을 직관적인 프로그레스 바로 표시합니다.
* **스마트 경고 시스템**: RAM 점유율이 90%를 초과하면 텍스트 색상이 변경되어 리소스 관리 타이밍을 알려줍니다.
* **저사양 최적화**: 하드웨어 관리와 소프트웨어 최적화를 통해 CPU 온도 40도 미만의 쾌적한 구동 환경을 보장합니다.

### 🛠️ 기술 스택 (Tech Stack)

* **Framework**: .NET 8.0
* **UI**: WPF (Windows Presentation Foundation)
* **Language**: C#
* **Management**: [VSCleaner](https://github.com/mikuchan1004/VSCleaner) 연동 권장

---

### ⚙️ 설치 및 사용 방법

1. [릴리즈](https://github.com/mikuchan1004/windows-simple-dashboard/releases) 페이지에서 최신 실행 파일을 다운로드합니다.
2. 별도의 설치 없이 바로 실행하여 시스템 상태를 확인하세요.
3. RAM 부족 시 함께 개발된 **VSCleaner**를 활용하여 캐시를 정리하면 더욱 효과적입니다.
